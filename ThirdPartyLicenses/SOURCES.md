# Supplemental upstream license sources

The installed MathLive package does not include separate notices for the KaTeX
fonts and adapted KaTeX code. These unchanged license texts are included locally
so app builds do not need to download license documents.

- KaTeX: https://raw.githubusercontent.com/KaTeX/KaTeX/main/LICENSE
- KaTeX fonts: https://raw.githubusercontent.com/KaTeX/katex-fonts/master/LICENSE
- javascript-natural-sort: https://raw.githubusercontent.com/overset/javascript-natural-sort/master/LICENSE

Retrieved and checked on 2026-10-09. The javascript-natural-sort npm package
version 0.7.1 identifies the MIT license but does not ship its full text; the
full text above comes from its official upstream repository.
