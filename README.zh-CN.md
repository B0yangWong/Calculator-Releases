输入 `^` 就写乘方，输入 `/` 就写上下分数，输入 `1.6e-25` 就写科学计数法。继续在原式中编辑，随时看预览结果，按 Enter 保存一行。以前的算式也能修改；更改变量或前面的计算，后续相关结果会重新计算。

本仓库只公开应用下载、使用说明和示例截图，不公开应用源码。Calculator 是独立应用，不是 Desmos 官方产品，也没有嵌入其网站或专有代码。

**v1.1.0 / build 10：**需要 Apple Silicon Mac 和 macOS 14 或更高版本。在 macOS 27 上验证过，未在 macOS 14 实机验证，不提供 Intel 包。本版采用本机临时签名，没有 Apple Developer ID 签名，也未经过 Apple 公证，首次打开可能被系统拦截。下载前请阅读[安装与打开](#安装与打开)。

## 功能

| 功能 | 可以做什么 |
| --- | --- |
| 直接编辑公式 | 输入乘方、根式和上下分数，从上标或分母返回后接着编辑原式。 |
| 科学计数法与自然常数 | `e-25` 表示 $10^{-25}$，`1.6e-25` 表示 $1.6\times10^{-25}$，`10*e*3` 中的 $e$ 表示自然常数。 |
| 科学函数 | 四则运算、绝对值、百分数、阶乘、$\pi$、`ans`、三角及反三角、双曲及反双曲、对数、组合、排列、取整、最大公约数、最小公倍数和余数。 |
| 变量与自定义函数 | 定义 $a=5$ 或单参数函数 $f(x)=x^2+1$，在后续算式中重复使用。 |
| 列表与统计 | 逐元素运算，以及平均数、中位数、总和、标准差、方差等统计函数。 |
| 复数与矩阵 | 按需开启复数模式，使用常用矩阵运算。 |
| 可以继续修改的计算记录 | 编辑历史、重算相关结果、撤销、重做、复制、粘贴和导出。 |
| 简洁且可缩放的工作区 | 科学键盘按需展开；紧凑的模式选择和设置按钮，把更多空间留给算式。小窗口会调整键盘与变量栏布局。 |
| 物理等式与单位 | 输入等式，给已知量填数值和单位，在支持范围内自动求一个未知实数标量；兼容单位自动换算，并检查量纲。 |
| 可修改的物理常数 | 识别 $c$、$h$、$\alpha$ 等常数，也允许修改其数值与单位。大写 $E$ 不再被改成小写 $e$。 |
| 100 条物理公式 | 按四个分类浏览，中英文搜索，复制公式或添加为新计算行，不覆盖正在输入的草稿。 |
| 中英文界面 | 在设置中切换界面和菜单语言、主题与字号。正常重开后保留设置和未提交输入。 |
| 离线使用 | 不需要账号，没有遥测上传、云同步或自动更新检查。 |

## 直接输入公式

| 输入 | 含义 |
| --- | --- |
| `2^3` | 可编辑上标：$2^3=8$ |
| `(2+3)/2` | 可编辑上下分数：$\frac{2+3}{2}=2.5$ |
| `e-25` | $10^{-25}$ |
| `1.6e-25` | $1.6\times10^{-25}$ |
| `10*e*3` | 自然常数：$10\times e\times3\approx81.5484548537714$ |
| `(e)-25` | $e-25$，这里 $e$ 是自然常数 |

浅色结果是按 Enter 前的预览，保存后颜色加深。上标或分母输入完后按右箭头回到原式；上标也可以按空格退出。科学计数法指数后的加减乘除会自动回到原式。

默认使用角度制，计算三角函数前请在展开的键盘中确认“角度 / 弧度”。百分号表示除以 100，不采用部分商用计算器根据上下文计算百分比的规则。

## 物理等式与单位

在窗口上方选择“物理”，或按 `Command + 2`。输入 $E=mc^2$，右栏会出现 $E$、$m$、$c$。$c$ 默认为真空光速，也可以自行修改。大写 $E$ 会保留，不会变成自然常数 $e$。

给已知量填写数值和单位，待求量的数值留空。例如 $m=1\,\mathrm{g}$、$c$ 保持默认值，会得到约 $E=8.987551787\times10^{13}\,\mathrm{J}$。可以指定兼容的显示单位，如 `eV`；也可以填写能量、留空质量，在支持范围内反求质量。单位栏也接受 `ev`，按 `eV` 处理。

- 单位填在变量栏或结果单位栏，不把公式里的字母混作单位。已知量必须填单位；无量纲量填 `1`。待求量的单位可以留空推导，也可以指定兼容的显示单位。
- `J*s`、`kg*m/s^2`、`s^(-1)` 分别表示 $\mathrm{J\,s}$、$\mathrm{kg\,m\,s^{-2}}$、$\mathrm{s^{-1}}$。单位区分大小写。单位栏里的 `F` 是法拉；力变量 $F$ 通常使用 `N`。
- 内置常数包括普朗克常数 $h$、精细结构常数 $\alpha$ 和玻尔兹曼常数 $k_B$。普通 $k$ 是用户变量；元电荷使用 $q_e$，不占用自然常数 $e$。
- 变量定义在整个物理工作区内共享。修改数值或单位会重算物理历史，不影响科学模式。重复使用名称前，要核对其含义；相邻字母可能命中内置别名，乘积建议明确输入乘号。
- 只剩一个未知量时，在支持范围内自动求解；多个未知量需要继续填已知量。多个实数解会全部显示，不替用户选择物理上合理的解；全部量都有值时，会检查等式是否成立。

量纲检查可以发现不兼容的相加和单位换算，但不能证明物理公式正确。它不是通用符号求解器，不支持任意非线性方程、联立方程、误差传播、向量、算符和微积分自动求解。温度目前只支持开尔文 `K`，不支持带零点偏移的摄氏、华氏温度换算。

## 物理公式表

在物理模式点击“公式表”，或按 `Command + Shift + F`。公式表可离线使用，目前收录 100 条常见大学物理公式：

| 分类 | 数量 |
| --- | ---: |
| 经典力学 | 28 |
| 分析力学 | 22 |
| 量子力学 | 24 |
| 热力学 | 26 |

可以用中英文名称、变量、希腊字母或公式片段搜索。鼠标停在条目上，或用键盘聚焦条目，会出现“复制”和“添加到计算”；窄窗口中也可以使用这两个操作。每条附变量含义、推荐单位、适用条件和教材或课程来源。只有点击来源链接时，才在外部浏览器打开网站。

“添加到计算”新建一行，不覆盖未完成的草稿，也不覆盖已有变量的数值、单位或常数修改。新普通变量可预填推荐单位，不会编造数值。使用前请核对共享变量是否适合新公式。“复制”会把标量式复制为可直接输入的文本等式，把参考式复制为 LaTeX。

其中 **77 条是标量关系，23 条是参考公式**。标量关系可以在当前单未知量求解范围内代入参数，但不代表每条公式的每个变量都能反求。参考式保留导数、积分、向量、算符或不等式，可以查看、复制和保存，暂不自动计算。物理限制、允许的量子数和多解选择仍需用户判断。这是常用公式精选，不是完整教材；量子分类里的静质量与静能关系明确标为相对论补充。

公式说明独立编写，并依据 [OpenStax 大学物理](https://openstax.org/subjects/science) 和 [MIT 开放课程](https://ocw.mit.edu/)核对。常数依据 [NIST / CODATA](https://physics.nist.gov/cuu/Constants/index.html)，单位约定依据 [BIPM SI 手册](https://www.bipm.org/en/si-brochure-9)。

## 安装与打开

1. 从 [v1.1.0 发布页](https://github.com/B0yangWong/Calculator-Releases/releases/tag/v1.1.0) 下载 [Calculator-1.1.0-macOS-arm64.zip](https://github.com/B0yangWong/Calculator-Releases/releases/download/v1.1.0/Calculator-1.1.0-macOS-arm64.zip)。新版本可在[最新发布页](https://github.com/B0yangWong/Calculator-Releases/releases/latest)查看。
2. 解压后把 `Calculator.app` 拖入“应用程序”。替换旧版本前先正常退出，不需要安装 Xcode、登录账号或另装运行环境。
3. 打开应用。若被 macOS 拦截，只在信任下载来源、确认文件未被篡改并愿意承担风险时继续。先尝试打开，再进入“系统设置 → 隐私与安全性”，选择“仍要打开”并确认，具体见 [Apple 官方说明](https://support.apple.com/en-us/102445)。受管理的设备可能没有这一选项。若系统提示文件已损坏或会损害电脑，请停止打开并反馈，不要关闭系统安全保护。
4. 用 `Command + ,` 打开设置，选择中文或 English、主题与字号，计算前检查角度模式。

发布页附带 `SHA256SUMS.txt`，可与下载 ZIP 的校验值比较，检查文件是否在下载中损坏。校验值一致不等于确认发布者身份、证明应用安全或得到 Apple 认可。

GitHub 自动提供的 `Source code (zip)` 和 `Source code (tar.gz)` 只有本仓库的公开文档、示例图片和第三方说明，不含应用源码，也不是安装包。请下载带版本号的应用 ZIP。

## 常用操作

| 操作 | 快捷键或方式 |
| --- | --- |
| 保存当前计算 | `Enter` |
| 离开上标或分母 | 右箭头；上标也可按空格退出 |
| 回到输入行 | `Command + N` |
| 撤销 / 重做 | `Command + Z` / `Command + Shift + Z` |
| 复制 / 粘贴 | `Command + C` / `Command + V` |
| 导出历史 | `Command + Shift + E` |
| 清除历史及未提交输入 | `Command + Shift + Delete` 或“清除全部”；当前会话中可以撤销 |
| 打开设置 | `Command + ,` 或设置按钮 |
| 显示 / 隐藏科学键盘 | `Command + K` 或键盘按钮 |
| 科学 / 物理模式 | `Command + 1` / `Command + 2` 或模式选择 |
| 打开物理公式表 | `Command + Shift + F` 或物理模式中的“公式表” |
| 打开输入说明 | `Command + /` 或应用菜单中的“帮助” |

历史和未提交输入会保存在本机。普通运行有单实例保护，防止不同应用进程同时写同一份历史；强制退出或断电不等同于正常退出。

## 隐私与当前限制

历史、草稿、设置、模式选择、物理变量的数值与单位，以及公式表条目关联，保存在本机 `~/Library/Application Support/FormulaDesk/state.json`，保留的目录名不影响应用名称。记录并未由应用加密。复制、粘贴和导出由用户触发；计算和公式搜索无需联网，点击来源链接才会在外部浏览器访问网站。系统备份和诊断服务另受 macOS 设置控制。保存和删除细节见[隐私说明](PRIVACY.md)。

- 一般计算使用浮点数，显示 15 位有效数字，不是任意精度计算器。纯数字有理数算式有精确分数路径；结果的分数 / 小数切换也仅适用于这类算式。
- 最多保存 250 行历史；列表最多 1024 项；阶乘最大为 170；矩阵最大为 32 × 32。
- 列表范围写法、列表索引、多参数自定义函数和递归函数未实现。
- 绘图、求导和积分尚未实现，也不保证与 Desmos 的所有行为一致。
- 物理模式支持范围内的单未知实数标量等式，不是任意方程或联立方程求解器。量纲一致不代表物理正确；参考公式不会自动求解，共享变量和物理限制需自行核对。
- 测试无法覆盖所有算式和全部 Mac。较旧的支持系统与全新 Mac 的首次打开仍需实机验证。重要计算请独立核对，特别是单位、角度模式和精度。

更新需手动下载。正常退出后替换应用，不要删除其 Application Support 数据目录；版本变化见[更新记录](CHANGELOG.md)。

[反馈问题](https://github.com/B0yangWong/Calculator-Releases/issues/new/choose)时，请提供算式、实际和期望结果、角度模式、应用版本及系统版本。[功能建议](https://github.com/B0yangWong/Calculator-Releases/issues)也可以提交。内容会公开，不要上传私人历史或敏感截图。
